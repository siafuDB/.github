# Code of Conduct

All projects under [`siafuDB`](https://github.com/siafuDB) adopt the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as their code of conduct. The full text is canonical at that address.

## Scope

It applies in every community space the organization owns or operates:
repositories, issues, pull requests, discussions and official channels,
and when an individual officially represents the organization in public.

## Reporting

Report privately. Do not open a public issue for a Code of Conduct
concern. Email **<hi@nyuchi.com>** with the subject line
`[Code of Conduct] <brief description>`. Reports go to organization
leadership and are treated in confidence, without retaliation against the
reporter. For abuse on GitHub itself, use GitHub's report abuse form.

## Enforcement

Maintainers enforce the standards fairly, following the Contributor
Covenant Enforcement Guidelines: correction, warning, temporary ban,
permanent ban.
